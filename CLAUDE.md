# This repository is a destination, not a workspace

Work on this project happens in `mvy0502/GenCP`, branch `tubitak-tr`.

This repository is the **handover copy**: a curated, readable snapshot for whoever takes
the project over. It is refreshed at milestones by copying the `tubitak/` tree from the
working repository.

Do not develop here. Do not merge branches into here. If you were sent here to do work,
you were sent to the wrong place — go to `mvy0502/GenCP`, `tubitak-tr`.

## Exception, from 2 September 2026: Project 2 lives here

`tubitak/sr/` — the Sentinel-2 super-resolution plugin, its models' training code, its
reports and its installation guide — has its **current** copy in this repository. It was
brought in as a subtree copy of tracked files from `mvy0502/GenCP` at `f28342b`, not as a
merge; `tubitak/sr/SOURCE.md` records the provenance. The copy left in GenCP is frozen.
Documentation and installation fixes for Project 2 happen here. The no-merge rule above is
unchanged: nothing about this copy involved merging history in either direction.
